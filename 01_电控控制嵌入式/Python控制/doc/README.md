# Python 控制

本目录集中保存 Python 控制实现，和 `ROS2控制/`、`嵌入式/` 分开维护。

## 目录

- `早期真机控制/`：16DOF 轮足在 ROS 2 主线之前的 IK、轨迹插值和真机接口验证；
- `最终Python部署/`：独立的 Python Sim2Real 运行方案，包含策略、IMU/电机接口、启动流程和安全模块。

Python 版本主要用于快速验证控制接口、策略输入输出、零位方向、站立流程和真机通信。需要运行最终比赛控制时，使用：

```text
../ROS2控制/
```

该 ROS 2 主线负责统一接入 Odin1、导航、比赛任务和 CAN 硬件。两个实现平台不要同时启动，避免重复连接电机和传感器。
