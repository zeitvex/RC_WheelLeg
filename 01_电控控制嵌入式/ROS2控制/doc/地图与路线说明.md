# 地图与路线说明

本目录中的 `map/` 保存最终控制运行时使用的点云地图和比赛路线。地图重建、重定位和航点编辑分别由 `04_定位` 与 `05_规划` 负责。

## Odin1 与路线的关系

```text
Odin1 扫图 / 重定位
  -> map -> odom 全局坐标
  -> Odin1 导出的 PCD 点云
  -> 05_规划/打点工具编辑航点和任务段
  -> map/routes/*.json
  -> 导航节点 -> cmd_vel_nav -> 策略
```

`.bin` 地图用于 Odin1 重定位，`.pcd` 点云用于查看场地和规划路线，`map/routes/` 中的 JSON 由运行时导航读取。三者必须保持同一套地图坐标系。

## 运行时资产

- `map/1hao.pcd`：比赛点云预览文件；
- `map/routes/`：比赛路线和任务分段；
- `src/odin_ros_driver/config/control_command_relocal.yaml`：重定位配置；
- `src/sim2real_bringup/config/runtime.yaml`：导航、策略和控制参数。

路线文件的编辑和安全检查统一在 `05_规划/打点工具/` 完成。确认路线后，再将运行时需要的 JSON 放入本目录的 `map/routes/`，避免维护第二份控制入口。

## 检查要点

1. Odin1 当前加载的 `.bin` 地图与用于打点的 `.pcd` 属于同一坐标系；
2. 路线航点、任务段和避障区域与场地模型对齐；
3. 机器人机身和轮腿足迹不会进入避障区域；
4. 重定位成功后，`map -> odom -> base_link` TF 连续且方向正确；
5. 导航输出经过 `cmd_mux` 和策略安全限制后再下发电机。
