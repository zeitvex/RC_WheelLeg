# Odin1 地图与打点工具说明

本目录中的工具以 Odin1 输出的点云地图为坐标参考，用于编辑比赛航点、任务段和避障区域，并在路线交给真机运行前进行离线检查。

## Odin1 在规划链路中的作用

Odin1 负责提供赛场点云、地图坐标和重定位后的全局位姿。打点工具不重新实现定位，而是在 Odin1 地图坐标系中生成导航所需的路线数据：

```text
Odin1 点云 / 地图
  -> PCD 查看与坐标确认
  -> 航点、任务段和避障区域
  -> 路线净空检查
  -> ROS2控制/map/
  -> 导航目标、策略切换和真机执行
```

比赛真机运行时，Odin1 输出的 `map -> odom` 全局坐标关系与路线文件必须使用同一套地图坐标系。重新扫图或重新导出地图后，应重新确认点云原点、航点和场地模型是否一致。

## 工具和数据

工具入口：[`../打点工具/`](../打点工具/)

- `nav_map_viewer.py`：查看 PCD、场地 XML、航点和避障区域；
- `avoid_region_tool.py`：编辑独立避障多边形；
- `route_safety_check.py`：检查路线与避障区域的净空；
- `route_candidate_optimizer.py`：生成航点候选；
- `run_route_experiments.py`：批量执行路线检查和 Sim2Sim 验证；
- `annotate_odin1_relocalization_frame.py`：辅助标注 Odin1 重定位参考图；
- `pcd/`：用于显示和人工打点的点云预览；
- `points/`：航点和路线 JSON；
- `xml/`：比赛场地模型；
- `regions/`：避障区域数据；
- `assets/`：坐标和机构示意图。

路线文件由规划工具生成，运行时由
[`01_电控控制嵌入式/ROS2控制/`](../../01_电控控制嵌入式/ROS2控制/)
中的导航与比赛任务模块读取。规划工具本身不直接控制电机。

## 基本使用

在 `05_规划/打点工具/` 目录执行：

```powershell
# 查看 Odin1 点云并编辑航点
uv run --with-requirements .\requirements.txt `
  python .\nav_map_viewer.py

# 编辑避障区域
uv run --with-requirements .\requirements.txt `
  python .\avoid_region_tool.py --pcd .\pcd\1hao.pcd

# 检查默认路线
uv run python .\route_safety_check.py

# 使用 MuJoCo 进行路线 Sim2Sim 验证
uv run --with-requirements .\sim2sim\requirements.txt `
  python .\sim2sim\nav_route_sim2sim_check.py
```

批量检查时显式指定输入路线，实验结果另存到新的输出目录：

```powershell
uv run --with-requirements ..\..\02_软件算法\训练仿真\sim2sim\requirements.txt `
  python .\run_route_experiments.py `
  --points .\points\points_20260715_120154.json
```

## 交给真机运行前

1. 使用 Odin1 当前实际加载的点云地图打开 `nav_map_viewer.py`。
2. 确认航点、任务段和避障区域都位于同一地图坐标系。
3. 执行 `route_safety_check.py`，处理净空不足或坐标偏移。
4. 使用 `nav_route_sim2sim_check.py` 检查路线与策略切换。
5. 将确认后的路线文件放入 ROS2控制 的 `map/`，再按
   `01_电控控制嵌入式/ROS2控制/doc/` 中的部署说明启动系统。

PCD 预览文件用于人工查看和打点，不替代 Odin1 建图、定位精度评估或高密度点云算法测试。地图重定位、设备连接和 `map -> odom` 配置见
[`04_定位/doc/`](../../04_定位/doc/)。
