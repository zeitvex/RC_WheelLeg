# 16DOF 轮足机器人 · Bonjour

> Bonjour（皮带绷住...）૮₍ •ᴗ•ₐა

大家好！本次为大家带来的是 **Bonjour** 上场参赛的最终版本。

我们在 8DOF 的基础上进行了以下升级：

## 1. 机身主板与髋关节固定优化

身体前后两片主板新增了两个髋关节电机的固定位置，并将材料由铝合金更换为碳纤维，以减轻重量、提升美观度。

## 2. 传动连接结构调整

移除了 8DOF 中的"电机连接2"，新增了转接件，将大腿电机与髋关节电机直接相连。

## 3. 小腿板轮足适配

将小腿板修改为适配轮足版本，并提供了一版小腿板模型，其孔位可兼容轮子与宇树足端的拆卸切换。不过这个方案实际并不太适合我们队，所以最终被否掉了，如果大家想要的话可以找我们提供。

## 注意事项

### 1. 传动方案建议

建议将"齿轮+皮带"的传动方式改为**连杆传动**，作为大腿与小腿之间的传动方案。在解决后腿电机发热的同时还可以增强设备在转弯时的刚性。

我们在 26 赛季使用皮带时遇到的问题是：齿轮会将皮带拉得过紧，给电机输出轴施加极大的径向载荷；再加上 Bonjour 整体重心偏后，导致后小腿电机发热严重。同时，皮带还可能面临老化、被齿轮磨平、跳齿、以及因过于紧绷而断裂等风险。

> 注：因为 Bonjour 的皮带在实际调试中并未出现皮带绷不住断裂的情况，所以给它起名 Bonjour（绷住了...）૮₍ •ᴗ•ₐა

### 2. 轮子材质建议

轮子部分我们全部使用 **PETG** 材料。但强烈强烈建议外侧轮毂使用**玻纤板或碳纤板**代替，否则外侧轮毂与电机输出轴相连的位置会直接断裂（实测）。

### 3. 后续开源计划

Odin1 保护壳、Nano 固定盒等文件后续会陆续开源。
