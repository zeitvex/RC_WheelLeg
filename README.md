# 基于 Odin1 的轮足机器人开源项目

本目录整理 RC_WheelLeg 轮足机器人项目中与 Odin1 相关的开源资料。Odin1 是整机感知与定位链路的上游设备，负责提供 IMU、图像、点云、里程计和重定位结果；下游控制、算法、规划和比赛任务基于这些数据完成真机运行。

Odin1 为我们的团队省下了一整个视觉组的工作，使我们能够有更多的时间去准备其他工作。在比赛系统中，Odin1 的 IMU 直接参与策略观测、站立平衡和安全保护，地图重定位结果则为导航和比赛任务提供全局坐标基准。

## 系统关系

```text
Odin1
  -> odin_ros_driver
  -> IMU / 图像 / 点云 / 里程计 / TF
  -> 地图重定位
  -> 规划与比赛路线
  -> sim2real 策略
  -> 电控与硬件桥接
  -> CAN 电机
```

## 运行入口

最终比赛 ROS 2 系统位于：

[`01_电控控制嵌入式/比赛任务集成/`](01_电控控制嵌入式/比赛任务集成/)

```bash
cd <workspace>
colcon build --merge-install --cmake-args -DCMAKE_BUILD_TYPE=Release
source install/setup.bash
./runros.sh
```

运行前先阅读：

- [`04_定位/doc/`](04_定位/doc/) 中的 Odin1 设备与重定位说明；
- [`01_电控控制嵌入式/比赛任务集成/doc/部署指南.md`](01_电控控制嵌入式/比赛任务集成/doc/部署指南.md)；
